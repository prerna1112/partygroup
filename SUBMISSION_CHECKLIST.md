# Assessment Submission Checklist

## Recording plan (maximum five minutes)

Use a mobile-sized browser window and keep the recording focused on product behavior.

1. **Landing and permissions (0:00–0:35)**
   - Show location permission or the New Delhi fallback.
   - Continue through the branded welcome screen.
   - Open the Terms and Conditions dialog, close it, then accept.

2. **Party discovery (0:35–1:05)**
   - Show the loading state and responsive party cards.
   - Select **Coffee Date** and click **Join this party**.

3. **Email and OTP validation (1:05–2:00)**
   - Blur an invalid email to show real-time validation.
   - Enter a valid email and show the submission spinner.
   - Enter an incomplete or incorrect OTP, then use `123456`.
   - Mention paste support and the resend countdown.

4. **Four-step profile wizard (2:00–3:35)**
   - Blur a one-character name to show validation, then correct it.
   - Use `extrovert` to demonstrate the unavailable-name response, then correct it.
   - Enter age `17`, show the eligibility error, then use an eligible age.
   - Select pronouns, go Back once to show state preservation, and continue.

5. **Failure, retry and success (3:35–4:35)**
   - Use invite code `FAIL500` to show the global submission alert.
   - Retry with `PARTY30`.
   - Show the success screen and return to the party list where the event is marked **Joined**.

6. **Submission (4:35–5:00)**
   - Upload the recording to Google Drive, YouTube (Unlisted), Loom or another host.
   - Confirm that anyone with the link can view it without requesting access.
   - Add that public recording URL to the company submission form.

## Final checks

- Recording is no longer than five minutes.
- The public link opens in a private/incognito browser window.
- No passwords, private notifications or unrelated browser tabs are visible.
- The deployed site URL and optional AI-chat link are ready to include.
